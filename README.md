# Перемена

Командная школьная викторина в браузере: https://kittler777.github.io/peremena-quiz/

## Как играть

1. Один игрок создаёт комнату и отправляет друзьям код или ссылку.
2. Друзья заходят с собственных телефонов или компьютеров и сами выбирают команды.
3. Ведущий выбирает предметы, 6–24 вопроса и 20–45 секунд на ответ. Нужно минимум две команды.
4. Всем одновременно показывается один и тот же вопрос. Команды пишут текстовый ответ и нажимают «Ответить».
5. Первый правильный ответ завершает раунд и приносит 100 очков. При неверном ответе другие команды сохраняют шанс до конца таймера. Каждая команда может отправить один ответ за раунд.
6. После результатов автоматически начинается следующий вопрос. В конце можно сыграть реванш в той же комнате.

До 32 игроков, 2–4 команды, 120 вопросов по математике, русскому языку, литературе, истории, географии и естествознанию. Регистр и «ё/е» не влияют на проверку; для имён предусмотрены короткие ответы, например «Пушкин» вместо полного имени. Не предусмотрено распознавание произвольных опечаток.

## Размещение

GitHub Pages обслуживает `index.html`, `style.css`, `app.js` и `config.js`. Сервер комнат размещён отдельной Railway Function на Bun. SQLite хранится на постоянном томе `/data`; комнаты удаляются после 24 часов без активности. Вход сохраняется в `sessionStorage` текущей вкладки. Секретные токены игроков не доступны другим участникам и не передаются в адресной строке.

API: https://quiz-rooms-production-e463.up.railway.app

Проект Railway: `118b9a8f-32be-457c-99a5-cbbcdd785f6e`

Сервис Railway: `841ea9ab-b4be-4ca6-8a35-a11fb22431d6`

Сервер работает в одном экземпляре, чтобы атомарно определять первую правильную попытку. Из-за сетевых задержек победитель определяется порядком получения ответов сервером. Игры с друзьями основаны на доверии: банк ответов открыт в исходниках.

Railway учитывает потребление сервера и тома по тарифу аккаунта. Публикация GitHub Pages и работа сервера — отдельные процессы; после изменения серверного кода требуется обновление Railway Function.

## Разработка

Node.js 24+; сторонние npm-зависимости не нужны.

```bash
npm test
npm start
```

Для работы локально замените адрес в `config.js` на пустую строку: `window.PEREMENA_API = '';`. Откройте http://localhost:3000. База создаётся в `data/`, её нельзя коммитить.

`node build.js` генерирует готовый одиночный файл `railway.ts` из проверенных исходников и браузерных файлов. Обновите Railway Function этим файлом. На Railway должен оставаться подключён том `/data` и домен с портом 3000.

Файлы `questions.js` и `answers.js` содержат вопросы и допустимые варианты ответа. После их изменения запускайте `npm test` и `node build.js`.
