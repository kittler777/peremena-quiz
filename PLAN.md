## 2. Правила — зафиксированы
- [x] 3–12 игроков; каждый играет за себя. Один ведущий создаёт комнату.
- [x] Вход по шестизначному коду или ссылке. После старта новые игроки ждут следующей партии.
- [x] Ведущий задаёт 3–10 раундов и 45/60/90/120 секунд на подпись. Одна картинка на раунд при любом составе: в партии картинки никогда не повторяются.
- [x] Этапы: ожидание → подписи → голосование → результаты → следующая подпись → финал. Ведущий переключает результаты; таймеры подписи и голосования ведёт сервер.
- [x] Всем назначается одна общая картинка на раунд. В следующем раунде — новая. Одна подпись до 200 символов, отправка окончательная. Пустая или неотправленная подпись пропускает раунд.
- [x] До голосования доступны общая картинка, своя подпись и статус готовности. При голосовании подписи перемешаны, авторов и текущих голосов нет в ответе API.
- [x] Каждый выбирает одну чужую подпись, затем подтверждает голос. Свою выбирать нельзя. Один голос окончательный. Игрок без подписи тоже голосует.
- [x] Голосование: 45 секунд; может закончиться раньше, когда все имеющие выбор проголосовали. Нет подписей — сразу результаты. Есть одна подпись — её автор не обязан голосовать.
- [x] Наибольшее положительное число голосов даёт +1 балл. Ничья: +1 всем лидерам. Ни одного голоса — никто не получает балл.
- [x] В результатах раскрываются авторы и голоса, показываются победители и общий счёт. После финала ведущий возвращает ту же комнату в лобби.
- [x] Обновление страницы сохраняет игрока, комнату и черновик. Повторный запрос не создаёт повторную подпись или голос. Устаревший раунд отклоняется.
- [x] Уход ведущего передаёт роль следующему игроку. Через 45 секунд без запросов игрок считается отключённым; через 90 секунд ведущий меняется автоматически. Таймеры ограничивают ожидание отключённых участников.
- [x] Сессии и игра сохраняются в SQLite. История увиденных картинок сохраняется для устройств всех участников, в том числе между новыми комнатами. Сначала выбираются картинки, которых никто из участников ещё не видел; после исчерпания — наименее недавно показанные. Конечный банк не гарантирует вечного отсутствия повторов.
- [x] Имена, подписи и ссылки выводятся безопасным текстом. Авторизация отдельным секретом игрока; секреты не попадают в общедоступное состояние.
